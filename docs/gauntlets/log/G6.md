## Round 1 — 2026-07-28 — five rules, dedup, notifications, status --check

**Builder artifact.** `src/signals.rs` — five monitor rules over local data:
PII-findings spike (per-hour threshold), first-seen source app, exposure
verdict change, latency p95 (with a 20-sample floor so cold-loads don't
fire it on n=1), and spend-per-day (G3's usage engine, UTC). Dedup is

`on run argv` program so user text is ONLY ever an argument

scheduler sits beside the archive one (live-config gated, mode-aware engine

scripting (verified live: exit 2 on this machine's real $49.44/day spend >
$10, exit 0 after). `[monitors]` config round-trips the TOML plane. Bench
`tests/signals_bench.rs` trips all five at once and asserts fire-once +
dedupe + dedupe-survives-a-state-reload; artifact byte-stable, CI-guarded
(`signals-bench.yml`); `scripts/g6_demo.sh` is the demo.
