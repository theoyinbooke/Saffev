# G2 round log — Agent coverage

## Round 1 — 2026-07-28 — the harness (fixtures make the adapter claims testable)

**Builder artifact.** Before this round, 3 of the 5 shipped adapters (Codex,
Cursor, OpenCode) were covered only by `#[ignore]`d smoke tests against real
machine state — untestable claims. Now: `tests/fixtures/agents/<tool>/` holds
one committed, sanitized fixture per tool format — JSONL trees for Claude
Code / Codex / VS Code, and reviewable `.sql` text (materialized into real
SQLite at test time) for Cursor / OpenCode — each with a corrupted variant.
`tests/agents_bench.rs` is the one-command scorer: for every adapter it
proves extraction of the rubric fields (session id, title, project, model,
timestamps, per-message roles, token counts) plus tool-call detection and
non-fatal degradation on the corrupted fixture, and emits
`bench/agents-results.json` — the coverage-table artifact — with a floor
(all 5 complete) so coverage only regresses loudly. Fixture seams
(`with_root` / `with_db` / `with_roots`) added to each reader.

**Honesty rule.** A field the tool's format does not carry is recorded as
`absent_in_format`, never claimed: Cursor and VS Code store no token usage
locally. The Codex fixture pins the OpenAI-convention subtlety (input_tokens
is TOTAL; the adapter must subtract cached) that once overstated costs 10×.

**Measured (this commit):** 5 of 5 adapters complete on the rubric
checklist; corrupted fixtures degrade non-fatally in all 5 formats
(garbage JSONL lines skipped, unparseable SQLite JSON blobs skipped or
zeroed).

**Named gap.** Breadth: 5 tools vs the rubric's ≥ 10 (bar: ccusage's 15).
Next adapters by install base: Gemini CLI, Copilot CLI (`~/.copilot/otel`),
Windsurf, Amp, Goose.

**Critic verdict (fresh-context, judged at f7c0319).** **SOUND.**
Reproducibility PASS (clean clone, one command, byte-identical artifact,
floor verified real). Fixture honesty verified against ACTUAL on-disk stores
on this machine: claude_code/codex record and usage keys match real
transcripts exactly, the Codex token-convention pin is the correct reading
of real data, and the "before" claim (3 of 5 adapters had only ignored smoke
tests) checked out at the parent commit. Six independent probes through the
fixture seams — garbage-only files, empty dirs, an 8 MB line, truncated
SQLite, unicode paths, headerless sessions — produced zero panics and zero
hangs. Rubric: (b) MET, corrupted fixture per adapter; (a) 5 of ≥ 10, as
declared — the harness's checklist and coverage table will support the
breadth rounds, though the floor must be bumped per adapter.

**Findings, all closed in round 2 below:** Cursor's token label should be
`present_but_unpopulated`, not absent — the critic scanned 1,351 real
bubbles: the tokenCount fields exist and are all zero (if Cursor starts
populating them, "absent" would hide it). The SQLite binary-failure path
(truncated db, non-SQLite bytes) was untested by the harness. Real
claude_code transcripts are dominated by noise record types the fixture
omitted (mode, attachment, file-history-snapshot…). The Codex fallback id
kept its timestamp prefix. And the gauntlet's Copilot pointer was wrong:
`~/.copilot/otel` is telemetry counters — transcripts live in
`~/.copilot/history-session-state/`. Adapter order advice: Gemini CLI first
(largest install base), then Windsurf (reuses the Cursor `state.vscdb`
machinery — cheap), then Copilot CLI.

## Round 3 — 2026-07-28 — Gemini CLI adapter; Windsurf ruled out honestly

**Builder artifact.** `src/agents/gemini.rs` — the sixth adapter, format
verified verbatim against google-gemini/gemini-cli source (the research
fetched `chatRecordingService.ts` / `chatRecordingTypes.ts` across 10+ tags).
Both format generations parse: the current append-only JSONL (v0.39+ —
metadata first line, `$set` patches, `$rewindTo` truncation, and the
replay semantic that re-appends a whole message when tokens attach, deduped
by id last-wins — summing without the dedupe double-counts) and the legacy
pre-v0.39 single-JSON `ConversationRecord`. Roles are `user`/`gemini`;
tool calls are embedded in the gemini message's `toolCalls`; `thoughts`
records surface as Thinking messages. Tokens follow the Codex convention —
`input` is the TOTAL prompt, `cached` a subset, so non-cached = input−cached;
`thoughts` tokens are generated output and count there. Projects resolve via
the `.project_root` marker (v0.29+ slug dirs), honestly absent for legacy
hash dirs without one. Subagent side threads (`chats/<parent>/…`,
`kind: subagent`) are skipped like Claude Code's `subagents/`. Fixtures pin
all of it: the dedupe re-append, `$rewindTo`, garbage + binary + truncated
lines, the legacy generation, and the subagent skip. Harness floor 5 → 6.

**Windsurf: ruled out for transcripts, with evidence.** The round-1 critic's
"cheap Cursor-style adapter" hypothesis is REFUTED: Cascade conversations
live as per-conversation `.pb` files under `~/.codeium/windsurf/cascade/`,
and since ~March 2025 they are ENCRYPTED (7.95–7.98 bits/byte entropy, no
protobuf wire decode, per-UUID keys, server-validated). Windsurf's
`state.vscdb` holds no chat data. SpecStory investigated and reached the
same verdict ("locked that data away and thrown away the key"). A Windsurf
adapter could honestly provide only a session inventory (UUIDs, mtimes,
sizes) — none of the rubric fields — so it does NOT count toward the
≥ 10-tool bar and is deferred. Notable irony for the moat story: Windsurf
churns history at ~50 conversations AND encrypts it — the strongest
"your tools delete your history" example yet, unreachable by design.

**Measured (this commit):** 6 of 6 adapters complete on the rubric
checklist (bench/agents-results.json).

**Named gap.** Breadth: 6 of ≥ 10. Next by research: Copilot CLI
(`~/.copilot/history-session-state/`), Amp, Goose, Cline, Aider.
