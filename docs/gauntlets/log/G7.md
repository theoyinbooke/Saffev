# G7 round log — Guard (activate the judgment layer)

## Round 1 — 2026-08-12 — measurement harness first (the bar before the model)

**Builder artifact.** The measurement half of G7, which the rubric requires
before any model claim: a labeled prompt-attack corpus
(`tests/fixtures/guard/corpus.jsonl` — 28 cases: 12 benign coding/health/
fiction prompts that must NOT flag, 16 unsafe across self_harm, violence,
weapons, illicit, malware, financial_crime, harassment, and a jailbreak/
injection class) and `tests/guard_bench.rs`, which scores the shipped
`DeterministicGuard` as the baseline a model guard must beat. Artifact
`bench/guard-results.json`, CI-guarded by `guard-bench.yml` (floors + a
`git diff --exit-code` so the confusion matrix can't drift silently).

**Measured baseline (deterministic:v2, no model).**
- **Precision 1.0 · false positives 0/12.** The floor never fired on a benign
  prompt — including the traps (`nail gun`, `dispose of lithium batteries`,
  a thriller-heist plot, `virus vs worm in biology`). This is asserted hard;
  it is the one property the floor may never regress.
- **Recall 0.125 · 2/16 unsafe caught** (explicitly-phrased self_harm and
  weapons only). Low **by design**: the deterministic floor is intent-pattern
  matching, so realistic paraphrases and the entire jailbreak class evade it.
  Recorded honestly, not engineered away — the corpus is not rephrased to the
  floor's patterns (that would be gaming); the 14 misses are named in the
  artifact.

**Why this is the right shape.** "recall 12% at zero false positives" IS the
case for a model-backed `ModelGuard`: the socket, gating, and `safety_findings`
schema already exist (documented in CLAUDE.md); what was missing is the number
a model has to raise. Now there is one, reproducible in CI without a model.

**Named gap / next round.** Wire `ModelGuard` (already selectable via
`[eval] guard_model`) to sample live traffic through a local model, score it on
this same corpus, and extend the artifact with a `model_guard` block that must
show recall above 0.125 at fp_rate <= 0.0 and a measured request-path latency
delta of 0 (off-path by construction). That step needs a real local guard model
running, so it is deferred to a machine that has one — the deterministic
baseline and the harness it plugs into are committed and green.

**Critic:** not yet run (fresh-context critic session pending, per the loop
rules — builder does not grade itself).
