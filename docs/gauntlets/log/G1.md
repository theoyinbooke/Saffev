## Round 3 — 2026-07-27 — breadth to 8 kinds, critic's corpus gaps closed

**Builder artifact.** Two new kinds: `env_assignment` (`.env`-style credential
assignments — segment-validated key, placeholder/interpolation/entropy-gated
value, defers to specific kinds when the value is itself a prefixed API key or
JWT) and `crypto_wallet` (legacy BTC via **real base58check double-SHA-256**,

EC PEM bodies; thin kinds thickened. Corpus 87 → 119 cases (45 traps).
