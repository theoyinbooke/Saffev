## Round 2 — 2026-07-28 — blocks, burn, and plan progress in the Studio

**Builder artifact.** `/api/agents/analytics` now carries the G3 usage
report: last 30 UTC daily rows, last 20 billing blocks (gaps included),
overall totals, and plan progress for the active block. Plan allowances are
honest by design: with no configuration the baseline is the user's highest
OBSERVED block (labeled "observed-max" — no invented dollar grants); setting
`pricing.plan` + `pricing.plan_block_allowance_usd` switches to the user's
own estimate, and the UI always says which one it is showing. The Usage tab
renders the active block's spend, live burn ($/h and tok/min), projection at
current pace, reset countdown, a plan progress bar, and the last 7 days
(cache reads and writes as separate columns), footnoted with the pricing
table's as-of date and the no-fetch invariant.
