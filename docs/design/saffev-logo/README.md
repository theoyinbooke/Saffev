# Saffev logo asset set

Selected direction: the two-part local recorder with one continuous trace.

## Canonical colors

- Brand green: `#11766E` (`--brand` in light mode)
- Light-mode cream: `#F5F0E8` (`--bg` in light mode)
- Warm ink: `#1C1A16` (`--text` in light mode)
- White: `#FFFFFF`

## Variants

- `saffev-mark-{green,white,cream}.svg`: transparent icon-only marks.
- `saffev-lockup-{green,white,cream}.svg`: transparent horizontal mark + wordmark.
- `saffev-mark-light.svg`: brand-green mark on the exact cream light-mode canvas.
- `saffev-lockup-light.svg`: brand-green mark, warm-ink wordmark, cream canvas.
- Matching PNG exports are generated from the SVG sources.

Use the solid white icon for the menu-bar/status-item treatment. Use the light
variant where the surrounding surface must be included in the delivered asset.
The transparent green mark is the default general-purpose brand asset.
